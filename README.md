## الجديد في النسخة دي

### الموقع (صفحة العميل)
- **تتبع الطلب**: زرار "تتبع الطلب" في الهيدر — العميل يكتب رقم الطلب ويشوف حالتها (استلام ← تحضير ← في الطريق ← تم التسليم). وبعد إنشاء الطلب بتظهر رسالة "تتبع طلبك" برقم الطلب.
- **زرار إنشاء حساب بيختفي** لما العميل يسجل دخول.
- **اللوجو من لوحة التحكم**: الأدمن يغيّره أو يشيله خالص (من الإعدادات).
- **الفرع إجباري عند الطلب**: العميل لازم يختار أقرب فرع من قايمة الفروع.
- **صور المنتجات أصغر** في الكروت (نسب Etoile) + بادجات "جديد" و"خصم %".
- **صفحة السلة والدفع** زي الصورة بالظبط: خطوات (السلة ← بيانات التوصيل ← الدفع) + صفوف المنتجات بالكمية والحذف + توصيل للمنزل/استلام من الفرع + طرق دفع (كاش شغال، البطاقات والمحافظ معطّلة بعلامة "متاح حالياً الدفع كاش فقط") + ملخص الطلب بكود خصم.
- **صفحة القسم** زي الصورة: فلتر جانبي (التصنيف + سلايدر السعر + متوفر/عروض) + ترتيب (الأكثر طلباً/الأحدث/السعر) + ترقيم صفحات.
- **صفحة المنتج** زي الصورة: معرض صور + بادجات + سعر قديم متشطب + الحجم + تابات (الوصف/المكونات/التقييمات) + منتجات مشابهة.
- **التسجيل برقم الموبايل وكلمة المرور بس** (من غير اسم ولا إيميل) — الاسم بيتسجل أول مرة من صفحة الطلب. ده بيوفّر مساحة الداتابيز.

### لوحة التحكم (الأدمن)
- **الرسائل اتشالت** من القايمة الجانبية.
- **التقارير**: كل حالات البيع باليوم/الأسبوع/الشهر/السنة (مبيعات + عدد طلبات + متوسط + ملغي + رسم بياني + سجل كل الطلبات) وفيها **زرار حذف جميع الطلبات** عشان مساحة الداتابيز.
- **الفروع**: إضافة/تعديل فروع — كل فرع فيه **رقم واتساب** بيوصل عليه طلب العميل.
- **المخزون**: تعديل الكميات بسرعة (− / رقم / +).
- **العروض**: خصم % على أي منتج — بيظهر في الموقع ببادج "خصم X%" وسعر قديم متشطب، وفي قسم الخصومات وفلتر "عروض".
- **الإعدادات**: تغيير **رقم موبايل الأدمن** و**كلمة المرور** اللي بيسجل بيهم + تحكم كامل في **اللوجو** (رفع/إخفاء/افتراضي) + حذف الرسائل.

### إشعار الطلب للفرع (واتساب)
لما العميل يأكد طلب، الموقع بيفتح **واتساب تلقائي** على رقم الفرع اللي العميل اختاره ورسالة الطلب متكتبة جاهزة (اسم العميل، الفرع، العنوان، المنتجات، الإجمالي) — الأدمن (أو موظف الفرع) يدوس "إرسال" بس.
> ملحوظة تقنية: المتصفح مش بيرسل واتساب أو SMS لوحده من غير سيرفر، فدي أقرب حاجة لـ"تلقائي": بيفتح الشات جاهز. لو عايز إرسال 100% تلقائي محتاج خدمة خارجية (زي Twilio أو واتساب API) باشتراك شهري.

## خطوات التشغيل

1. ارفع الملفات على GitHub (نفس فولدر الموقع الحالي).
2. الصق `firestore.rules` في Firebase ← Firestore ← Rules ← Publish (فيه تغيير مهم: مجموعتين جداد `branches` وقراءة عامة للطلبات عشان تتبع الطلب).
3. من لوحة التحكم ← **الفروع** ← ضيف فرع على الأقل برقم واتساب (من غير كده العميل مش هيلاقي فروع يختارها).
4. من **الإعدادات** ممكن تغيّر رقم الأدمن وكلمة المرور وتتحكم في اللوجو.
